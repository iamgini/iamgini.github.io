The File Checksum Integrity Verifier (FCIV)  is a command-prompt utility that computes and verifies cryptographic hash values of files. FCIV can compute MD5 or SHA-1 cryptographic hash values. These values can be displayed on the screen or saved in an XML file database for later use and verification. fciv filename more details : http://support.microsoft.com/kb/841290

If you have credits on Public cloud accounts, then you can use managed Kubernetes services such as [GKE](https://cloud.google.com/kubernetes-engine) , [AKS](https://docs.microsoft.com/en-us/azure/aks/) , [EKS](https://aws.amazon.com/eks/) etc. But building self-hosted Kubernetes clusters are not straightforward tasks as there are many components to be installed and configured. But there are multiple ways to automate the kubernetes cluster deployment by using infrastructure as code (IaC) tool such as Vagrant and Terraform. In this article, you will learn how to deploy a multi-node Kubernetes cluster using Vagrant and VirtualBox. With this method you can deploy and destroy Kubernetes clusters whenever you needed.

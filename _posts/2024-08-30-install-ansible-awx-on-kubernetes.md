[Ansible AWX](https://github.com/ansible/awx) is the upstream project for the [Ansible automation controller](https://www.redhat.com/en/technologies/management/ansible/automation-controller) (Part of Red Hat Ansible Automation Platform). It offers a web-based user interface, REST API, and a task engine built on top of Ansible. AWX is designed to be a frequently released, fast-moving project where all new development occurs.

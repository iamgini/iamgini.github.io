Dell has a beautiful tool for remote server management called iDRAC which is almost same like HPE iLO, but with different features. You can access iDRAC using GUI or via ssh. But what if you lost the login credentials for this iDRAC ? No need to worry, we have local racadm tool which we can use via windows or linux on the manged node. ( Remote racadm can be use same like ssh but still you need login credentials.) 

Read [How to install racadm for iDRAC on RHEL / Linux](https://www.techbeatly.com/how-to-install-racadm-for-idrac-on-rhel-linux/).
